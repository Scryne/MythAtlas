# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, report the issue privately via GitHub Security Advisories:
- Go to the repository's `Security` tab.
- Click `Report a vulnerability`.
- Include reproduction steps, affected routes/files, and potential impact.

We will acknowledge receipt as quickly as possible and work on a fix before public disclosure.

## Scope

Security reports are especially useful for:
- API and route-handler vulnerabilities.
- XSS, injection, SSRF, auth/session, or data-exposure issues.
- Supply-chain or dependency risks with practical impact.
